2、泛型

泛型

泛型就是 TS 里给 “类型” 装的 “万能适配口”—— 你不用提前定死要处理哪种类型（比如只处理数字、只处理字符串），等实际用的时候，再告诉它 “这次要适配哪种类型”，这样一个函数 / 接口就能搞定多种类型的需求，还不会丢了类型检查。

举个生活例子：就像你买了个 “通用收纳盒”，盒子本身没说只能装口红还是装笔，用的时候你放口红就是 “口红收纳盒”，放笔就是 “笔收纳盒”—— 泛型就像这个盒子，给 “类型” 留了个可调整的口子。
