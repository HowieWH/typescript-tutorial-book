3、类型转换

类型转换

主要介绍两种类型转换方式：别名和断言。

“类型转换”的核心作用是 在编译阶段调整变量的类型标注，解决 “类型不匹配”“类型模糊” 等问题，同时不影响代码的运行时行为。

注意：类型转换不会改变变量的实际类型，也不会改变变量在内存中存储的数据，只是改变了变量在编译阶段的类型标注。
