简介

本书介绍

本书是TypeScript的入门指南，入门中的入门，内容非常简单，非常适合想要简单了解和想要入门TS的同学。本书内容来自于GITHUB项目 AboutTypeScript速成教程（2小时速成），感谢原作者的付出。

我非常赞同原作者的观点："陌生使用者最迫切的需求应该是快速掌握工具的使用"。先学会简单的使用再说，项目中遇到具体的需求或者问题时，再深入学习。而且在实际项目开发中，TS的普遍使用场景也大多集中在简单的语法上。

一方面感受到内容非常不错，另一方面在阅读原项目时感觉不太方面。所以想到使用GITBOOK整理为电子书格式，方便大家阅读。
